# End-to-End Test Instructions (수동 브라우저 확인)

브라우저 자동화(E2E)는 범위에서 제외했습니다 (frontend 계획 결정). 같은 요청 흐름은 백엔드 통합 테스트로 검증되었으므로, 아래 절차는 **화면이 실제 백엔드와 맞물려 동작하는지** 사람이 한 번 확인하는 체크리스트입니다. 이 절차는 아직 실행하지 않았습니다 (실행 결과는 비워 둠).

## 준비

```powershell
cd frontend; npm install; npm run build
cd ..\backend; python scripts/seed.py --reset --yes      # 깨끗한 개발 데이터 (테이블 1~5, 메뉴 12개)
python -m uvicorn app.main:create_app --factory --port 8000 --timeout-graceful-shutdown 5
```

- 브라우저 창 2개를 준비합니다: 고객 태블릿 역할(창 A), 관리자 역할(창 B). 같은 PC의 서로 다른 브라우저/시크릿 창이면 localStorage가 섞이지 않습니다.
- 계정: 매장 `demo`, 관리자 `admin` / `admin1234`, 테이블 1~5 비밀번호 `1234` (`backend/.env.example` 기준)

## 체크리스트

각 항목의 "기대"를 확인하고 결과(O/X)와 메모를 기록하세요.
